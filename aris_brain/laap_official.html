关键架构决策

1. 白盒 > 黑盒

LLM 是概率黑盒，Harness 是确定白盒。不是让 LLM 做更多事，而是让 LLM 做更少事——只做编译，不做运行时。

2. 装配 > 生成

80% 的工程工作是有范式的。范式化的任务不需要"生成"，只需要"装配"。组件库 + 模板匹配 + 参数注入 = 零 Token 产出。

3. 欲望 > 指令

真正的智能体不是"你问它答"，而是有内在动机、主动探索、自发学习的。PSI 情感引擎让 Aris 有"想做什么"的能力。

4. 编译 > 解释

LLM 每次都重新理解世界。Harness 一次编译，永远运行。这是 Compiled AI 的核心——LLM 不是运行时，LLM 是编译器。
