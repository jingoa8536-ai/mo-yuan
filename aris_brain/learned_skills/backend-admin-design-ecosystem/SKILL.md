# B端/后台设计生态全指南

## 一、后台页面设计灵感与案例库

### Ant Design Pro
- 官网：https://preview.pro.ant.design/
- 定位：阿里系中台/后台设计标杆
- 涵盖：数据大屏、表格、表单等完整后台设计案例
- 配套：Ant Design 交互规范与元件库
- 适合：后台系统视觉参考 → **我优先看这个找布局和交互模式**

### AxHub
- 官网：https://axhub.im/discover/
- 定位：原型设计资源分享平台
- 内容：精选后台原型案例 + Axure 元件库
- 适合：参考后台交互逻辑与页面布局 → **需要页面结构时来看**

### Navbar Gallery
- 官网：https://www.navbar.gallery/type/side-bar
- 定位：侧边栏菜单设计案例收集
- 内容：大量优秀的侧边栏导航设计示例
- 适合：后台导航布局参考 → **做侧边栏先逛这里**

### SaasPo
- 官网：https://saaspo.com/
- 定位：SaaS 网站设计灵感平台
- 内容：大量 SaaS 后台/产品页设计案例
- 适合：现代 SaaS 后台界面参考 → **要做SaaS后台先看这家**

## 二、后台 UI 组件库与设计规范

### Ant Design 官方文档
- 官网：https://ant.design/components/overview-cn/
- 内容：完整 Ant Design 组件库、设计规范、最佳实践
- 适合：后台组件化设计的权威依据 → **组件样式/交互规范查这里**

### Element 后台元件库
- 获取方式：可通过 AxHub 等平台获取
- 内容：饿了么 Element 后台组件设计参考
- 适合：Vue技术栈的后台组件参考

## 三、原型与线框图设计工具

### 即时设计
- 官网：https://js.design/
- 定位：在线专业级原型设计工具
- 内容：大量网页原型模板（含后台模板）
- 功能：低保真→高保真设计
- 适合：快速搭建后台页面原型 → **快速出稿用这个**

### Balsamiq
- 官网：https://balsamiq.com/
- 定位：低保真线框图设计工具
- 功能：快速制作低保真原型
- 适合：后台设计初期梳理页面结构和交互逻辑 → **前期规划好工具**

## 四、综合设计灵感与资源库

### Design Vault
- 官网：https://designvault.io/
- 内容：真实 UI 设计模式和界面灵感
- 特色：大量后台界面 UI 模式参考
- 适合：寻找特定的界面设计模式

### Behance / Dribbble
- 官网：https://www.behance.net/ / https://dribbble.com/
- 定位：综合设计社区
- 搜索关键词：后台 / B端 / Admin
- 适合：获取全球设计师的前沿后台设计灵感

## 工作流指引

### 场景1：做一个完整的企业后台
1. **灵感收集** → SaasPo / Dribbble / Behance 搜同类
2. **布局结构** → AxHub / Navbar Gallery 定导航
3. **组件选型** → Ant Design + Element 定交互规范
4. **原型快速出稿** → 即时设计
5. **最终实现** → 配合已学技能（react-nextjs / tailwind-shadcn / python-fastapi）

### 场景2：优化后台侧边栏
1. → **Navbar Gallery** 找灵感
2. → **Ant Design** Menu组件规范
3. → **CSS-Tricks** 找动画实现方案

### 场景3：做SaaS后台产品
1. → **SaasPo** 看同类产品
2. → **Ant Design Pro** 看数据大屏方案
3. → **Design Vault** 找 UI 模式
